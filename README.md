# VitaVet

Sistema Web para la Gestión de Atención y Citas Veterinarias en VitaVet.

## Tecnologías previstas

- HTML5
- CSS3
- Bootstrap 5.3
- JavaScript

## Futuras tecnologías

- Spring Boot
- API REST
- Base de datos

## Estructura del proyecto

- frontend/pages: carpeta destinada a las páginas del sistema.
- frontend/css: archivos de estilos para la presentación visual de la interfaz.
- frontend/js: scripts para comportamientos e interacciones.
- frontend/assets: recursos estáticos como imágenes e iconos.
- backend: espacio reservado para una futura aplicación Spring Boot.

El desarrollo de las interfaces se realizará en fases posteriores.
